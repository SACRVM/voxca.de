Voxcade 0.4.1, the first release

Five games and the workshop to make your own, for Windows and Linux: unpack it, start it, play.

Voxcade is out of the workshop for the first time. Version 0.4.1 is one folder with five games and everything to make your own. There is nothing to install: download it, unpack it and double-click Voxcade. How to install walks through it step by step, and the quick start gets you to your own first game in five minutes.

What is in it

  • The launcher: start Voxcade and it lists the games. PLAY starts one, EDIT opens it in the IDE, the workshop where games are made, and NEW GAME begins one of your own from a template: a jump & run, a shooter, or empty.
  • Five games, each a folder of Lua and voxels: More Blood (a run-and-gun shooter, with pixel blood), Voxkeep (a jump & run in a castle at night), Sokovox (Sokoban with the Microban puzzles by David W. Skinner), Pulsar (a space shooter on the music's beat, for two) and BunnyFarm (a farming game). Each shows its keys as it begins, for the keyboard or the gamepad you play with.
  • The IDE: the code with the API's names offered as you type, the game playing in place, its errors pointing at the line; scenarios that start a run anywhere; HELP with the Lua API by example; BUILD, which packs a game to pass on. Editors for voxel models and for levels of voxel blocks come with it.
  • Playing together: several players at one screen, on the home network, and across the internet by a six-sign code (HOST ON THE INTERNET, then JOIN and TYPE A CODE). No ports to open; friends can join a game already running.
  • New versions by themselves: the launcher says when one is there, and UPDATE NOW fetches it, checks it and puts it in place. Your games, settings and saves stay.
  • Languages: the games' menus speak English, German and French and follow your system; BunnyFarm speaks all three throughout. The launcher and the IDE are in English.

Good to know

  • Windows may warn that it protected your PC: the program is not signed yet. Choose More info, then Run anyway.
  • Linux needs Vulkan graphics drivers and a current system (Ubuntu 24.04, Linux Mint 22, Fedora 40, Debian 13 or later).
  • macOS is not part of this release.
  • A game across the internet that cannot connect directly goes through our relay, and may stall for a moment now and then.

Voxcade is free, under the zlib licence, as LÖVE is: use it, make games with it, give them away or sell them. A game you make is yours. The licences of the libraries built into the program are in THIRD-PARTY-LICENSES.txt in the folder.

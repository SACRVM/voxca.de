Voxcade 0.4.1, die erste Version

Fünf Spiele und die Werkstatt für eigene, für Windows und Linux: entpacken, starten, spielen.

Voxcade verlässt zum ersten Mal die Werkstatt. Version 0.4.1 ist ein Ordner mit fünf Spielen und allem, um eigene zu machen. Installieren musst du nichts: herunterladen, entpacken und Voxcade doppelklicken. So installierst du es zeigt jeden Schritt, und der Schnellstart bringt dich in fünf Minuten zu deinem ersten eigenen Spiel.

Was drin ist

  • Der Launcher: Starte Voxcade, und es zeigt die Spiele. PLAY startet eins, EDIT öffnet es in der IDE, der Werkstatt, in der Spiele entstehen, und NEW GAME beginnt ein eigenes aus einer Vorlage: Jump & Run, Shooter oder leer.
  • Fünf Spiele, jedes ein Ordner aus Lua und Voxeln: More Blood (ein Run-and-Gun-Shooter, mit Pixel-Blut), Voxkeep (ein Jump & Run in einer Burg bei Nacht), Sokovox (Sokoban mit den Microban-Rätseln von David W. Skinner), Pulsar (ein Weltraum-Shooter im Takt der Musik, zu zweit) und BunnyFarm (ein Farmspiel). Jedes zeigt beim Start seine Tasten, für Tastatur oder Gamepad, je nachdem, womit du spielst.
  • Die IDE: der Code, mit den Namen der API beim Tippen angeboten, das Spiel läuft gleich daneben, seine Fehler zeigen auf die Zeile; Szenarien starten einen Lauf an jeder Stelle; HELP zeigt die Lua-API an Beispielen; BUILD packt ein Spiel zum Weitergeben. Editoren für Voxel-Modelle und für Level aus Voxel-Blöcken gehören dazu.
  • Zusammen spielen: mehrere an einem Bildschirm, im Heimnetz und übers Internet mit einem Code aus sechs Zeichen (IM INTERNET ÖFFNEN, dann BEITRETEN und CODE EINGEBEN). Keine Ports zu öffnen; Freunde können einem laufenden Spiel beitreten.
  • Neue Versionen von selbst: Der Launcher meldet, wenn es eine gibt, und UPDATE NOW holt sie, prüft sie und setzt sie ein. Deine Spiele, Einstellungen und Spielstände bleiben.
  • Sprachen: Die Menüs der Spiele sprechen Deutsch, Englisch und Französisch und richten sich nach deinem System; BunnyFarm spricht alle drei durchgehend. Der Launcher und die IDE sind auf Englisch.

Gut zu wissen

  • Windows warnt vielleicht, es habe deinen PC geschützt: Das Programm ist noch nicht signiert. Wähle Weitere Informationen, dann Trotzdem ausführen.
  • Linux braucht Vulkan-Grafiktreiber und ein aktuelles System (Ubuntu 24.04, Linux Mint 22, Fedora 40, Debian 13 oder neuer).
  • macOS ist in dieser Version nicht dabei.
  • Ein Spiel übers Internet, das keine direkte Verbindung findet, läuft über unser Relay und kann ab und zu kurz stocken.

Voxcade ist frei, unter der zlib-Lizenz, wie LÖVE: Nutz es, mach Spiele damit, verschenk oder verkauf sie. Ein Spiel, das du machst, gehört dir. Die Lizenzen der Bibliotheken, die im Programm stecken, stehen in THIRD-PARTY-LICENSES.txt im Ordner.

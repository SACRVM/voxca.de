Cookies & tracking

Short version: none of it.

This site sets no cookies, so there is no cookie banner: where nothing is collected, there is nothing to consent to. No analytics, no trackers, no forms, and nothing loaded from other servers: the fonts, pictures and films all live on this host.

What remains are the technical server logs of the hosting provider (GitHub Pages, GitHub Inc.), which include the requesting IP address; details are in the GitHub Privacy Statement. The downloads come from GitHub's release storage, so GitHub's servers see that request as well. Voxcade itself asks this site for one small file when its launcher starts, to learn of a new version (that can be switched off in the launcher); this request reaches GitHub's servers like a page view. Nothing else is sent.

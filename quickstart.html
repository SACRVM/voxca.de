Your first game in five minutes

From nothing to a jump & run of your own: Voxcade makes the game from a template, you play it, and change it while it runs. Voxcade is installed? Then off you go.

  1. Start Voxcade

    Double-click voxcade in the Voxcade folder (start-voxcade.sh on Linux). The launcher opens, with the games to play and, below them, NEW GAME.

  2. A new game

    Choose NEW GAME, type a name, pick JUMP & RUN and choose CREATE. Your game opens in the IDE, the workshop where games are made. It is a folder of its own, in Voxcade in your home folder (the gear at the top right changes where).

  3. Play it

    Press PLAY at the top right. The game shows its keys: the arrows run, Space jumps. Land on the slime, take the gems, out through the door. Escape takes you back to the code.

  4. Change a rule

    On the left, main.lua holds the game's rules. Near the top stands how high the hero bounces off an enemy. Change 50 to 150: the IDE saves by itself a second later. Press PLAY again: the game goes on where it was, with the new rule. Jump on the slime and see.

    local BOUNCE = 50        -- how high a hero bounces off an enemy, voxels

    Every number with a comment is yours to change; conf.lua holds the game's settings, from the hero's speed to the camera.

  5. Shape it

    Double-click hero.vox under MODELS: the voxel editor opens in a window of its own. Paint the hero: every change is saved at once, and the game shows it. level.json under LEVELS opens the level editor: place blocks and things.

  6. Pass it on

    BUILD packs the program and your game into one zip file in the game's builds folder, ready to give to a friend.

Where next

  • HELP in the IDE shows the Lua API by example: whole games to copy and change.
  • The five games lie in the games folder beside the program: EDIT in the launcher opens one, to see how it is made.
  • While a game plays, the key left of 1 opens the console: a line of Lua runs in the game, player.state.score = 5000 for instance.
